# 💫 About Me:
🧑‍💻 Sobre mí<br><br>Soy un programador joven, que hace poco termine mi carrera pero que actualmente estoy práctica profesional, dando mis primeros pasos en el mundo laboral con muchas ganas de aprender y seguir creciendo como desarrollador.<br><br>Me interesa principalmente el desarrollo web, backend y la creación de videojuegos, áreas donde disfruto tanto programar como resolver problemas y experimentar con nuevas ideas. Me motiva aprender buenas prácticas, entender cómo funcionan las cosas “por dentro” y mejorar proyecto a proyecto.<br><br>He trabajado y practicado con tecnologías como Python, JavaScript, HTML, CSS, y bases del desarrollo backend, además de Unity (C#) y Godot para videojuegos 2D. Este GitHub refleja mi proceso de aprendizaje: proyectos personales, pruebas, prototipos y avances constantes.<br><br>Siempre abierto a aprender nuevas tecnologías, recibir feedback y enfrentar desafíos que me permitan seguir creciendo tanto a nivel técnico como profesional 🚀
